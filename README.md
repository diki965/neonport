Solport — an original top-down 2D open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car: steal cars, outrun the police across a 0–5 star wanted system, run five story missions for Rosa, fight with fists and a pistol, shop at the Gun Barn, Clinic, Respray and Garage, hail taxi fares, and save at the Safehouse. Static files, no build step, no network requests, no libraries — every city, character, vehicle, name, story, sound and pixel is original.

## Run it

```sh
node serve.ts
# open http://localhost:8080/game/index.html
```
